# 존 윅 아카이브

존 윅 시리즈(영화 4편, 스핀오프 《발레리나》, TV 시리즈 《더 콘티넨탈》)를 정리한 비공식 팬 아카이브. Next.js App Router, 정적 생성.

- 데이터: `data/films.ts`, `data/characters.ts`, `data/world.ts`, `data/cars.ts`, `data/keanu.ts`
- 포스터·영화 스틸은 쓰지 않습니다.
- 방문자 수: Abacus `johnwick-archive` / `visits` (하루 1회, 테스트 방문 제외)
- 광고: 쿠팡 파트너스 (푸터 배너 + 하단 고정 배너 + 본문 카드, 페이지당 최대 3개)
